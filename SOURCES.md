## Source policy

Star counts and popularity are intentionally not hard prioritization inputs. The roadmap prioritizes architectural position, multiplicative fleet cost, adoption path, licensing, and whether a strong native implementation already exists.

All performance hypotheses in this repository should be tied to reproducible benchmarks before being described as fleet savings.
